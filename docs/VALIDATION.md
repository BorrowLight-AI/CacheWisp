# 验证与性能基准

[English](VALIDATION.en.md) | **简体中文**

## 当前基础工程命令

```sh
pnpm verify
pnpm tauri build --bundles app
```

verify 包含格式、TypeScript、生产前端构建、Rust 测试和 Clippy。原生应用另做启动、设置保存及重启恢复的 smoke 验证。结果记录在 INITIALIZATION.md。

## 功能验收矩阵

| 领域        | 必测案例                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------- |
| 范围        | 重叠根、嵌套根、目录符号链接、根本身是符号链接、worktree、权限不足、根删除                  |
| 规则        | 每生态正常布局、同名普通目录、缺少 manifest、Git 跟踪文件、用户源码混入、静态自定义路径越界 |
| 统计        | 大量小文件、空目录、硬链接跨项目/范围外、稀疏文件、APFS 克隆、取消及扫描中变更              |
| 层级        | monorepo、多语言、嵌套仓库、共享产物，保护子项目不能被父级选择绕过                          |
| 清理        | 预览后文件替换/变更、选择归一化、废纸篓失败、永久确认、部分成功、重复重试、退出中断         |
| 外置盘      | 断连、重连、相同挂载路径不同卷、不可写卷、不支持废纸篓的卷、旧预览失效                      |
| 监控        | 安装风暴、事件合并、睡眠唤醒、重新打开主窗口、隐藏精灵、明确退出后无残留                    |

| 预算        | 并发预留、重试、当天重启、日期/时区切换、0 次、改限额、手动统计独立                         |
| 双语/无障碍 | 系统语言、切换后保存、键盘/focus、原生对话框、深浅色、减少动态效果                          |

## 删除测试纪律

只操作测试明确创建的临时目录。每个测试 fixture 带独立父目录和清单，断言变更未越出该目录。禁止将用户真实项目或全局缓存设为自动测试目标。废纸篓测试需能够定位自身移入的目标，不清空系统废纸篓。

## 百万文件基准（CW-024 待实现）

生成器必须支持显式临时输出目录、seed、项目数、文件数、各生态布局、硬链接比例和 manifest；操作前核对根，避免在仓库/node_modules 中生成。

推荐数据集：100/300 个项目；100k/1m 文件；小文件为主，并包含硬链接、稀疏文件及重复根。记录逻辑体积与实体文件分布，确保比较相同 fixture。不能为了显示“大体积”就把稀疏逻辑大小认作已占物理空间。

每次报告：commit、build profile、CPU/内存、macOS/文件系统、存储介质、数据集参数、冷/热扫描耗时、峰值内存、CPU、取消响应、UI 响应、SQLite/索引体积、错误与不完整 scope。固定测试条件后才设定完整扫描速度门槛。

## 常驻预算门禁

- 使用 release 构建，主窗口已关闭，Wisp 显示，监控启用，无扫描或待处理变化。
- 记录根数、监听数、历史数据规模、联网/AI 状态，预热后采样至少 5 分钟。
- 合并核心及可归属的 WebView/helper 进程。说明 RSS/physical footprint 与共享页去重口径；不只记录主 PID。CPU 百分比统一到一个逻辑核 100%。
- 目标：相关进程合计内存 ≤150 MB；平均空闲 CPU <1%。同时报告峰值和采样分布，避免只挑最好瞬间。
- 补测隐藏 Wisp、重新打开窗口、持续文件变化和 AI 请求后的回落。隐藏后必须释放对应界面资源。
- 记录是否包含全局共享 GPU/helper 的归属限制；不可准确归属的开销须说明，不能悄悄遗漏。

## CI 与发布

CI 运行冻结锁文件安装、格式/类型/构建、Rust 单元与集成检查。原生 WebView 生命周期和硬件性能在真实 macOS 上验收，CI 编译通过不代表资源预算通过。签名、公证、Intel 及最低系统验证属于 CW-025。
