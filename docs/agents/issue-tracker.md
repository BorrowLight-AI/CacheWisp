# Local Markdown issue tracker

Tasks are tracked in .scratch/cachewisp/issues and indexed by docs/TASKS.md. This directory is intentionally committed, not temporary scratch data.

The authoritative product plan is docs/plan/PRODUCT-PLAN.md; .scratch/cachewisp/PRD.md points to it. Stable task IDs are CW-001 through CW-025.

Each task records Status, Type (AFK/HITL), priority, blocked-by IDs, user stories, end-to-end outcome, acceptance criteria and verification. A ready-for-agent triage label is not permission to ignore unresolved dependencies. Start only when every blocker is done.

A task is complete only after its acceptance criteria and real verification evidence are recorded. Update the task and index together. Future GitHub migration should retain local IDs and add actual issue links; no remote is required for current development.
