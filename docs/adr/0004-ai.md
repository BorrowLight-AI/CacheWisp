# ADR-0004：自配兼容服务、脱敏建议与调用预算

[English](0004-ai.en.md) | **简体中文**

状态：接受。日期：2026-10-26。

用户配置服务地址、Key、模型名，首版采用 Chat Completions 兼容接口。Key 留在系统凭证库，SQLite 不保存明文。AI 只接收统计代号、分类、计数和变化，真实身份映射留在本地。

本地规则聚合重要变化后请求 AI。默认每日 20 次自动分析，用户可调整，0 停用；发起前原子预留，重试计数，手动预设追问单独统计。无服务或额度时本地功能照常。

只提供建议卡片及预设追问。模型输出是不可信解释，不赋予文件系统/命令执行能力。因果推断明确为可能原因，动作入口只打开本地清理预览。
