# ADR-0005：常驻开销优先与按需窗口生命周期

[English](0005-residency.en.md) | **简体中文**

状态：接受。日期：2026-10-26。

主窗口关闭后菜单栏继续监控，明确退出终止后台。Wisp 可拖动和隐藏；隐藏不能停止用户已开启的监控。

Wisp 静止时停止刷新，隐藏释放渲染资源。主窗口与 AI 客户端按需加载。监控以原生事件、合并和有界局部核对实现，避免频繁全量扫描与每文件 IPC。

资源验收场景：关闭主窗口、Wisp 显示、监控开启、无扫描。相关进程合计内存 ≤150 MB，平均空闲 CPU <1%。在固定设备上测量并保存原始结果。超预算优先简化动画、窗口/状态和渲染适配器，不能虚报指标。
