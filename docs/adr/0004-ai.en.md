# ADR-0004: User-configured compatible services, anonymized advice and call budgets

**English** | [简体中文](0004-ai.md)

Status: Accepted. Date: 2026-10-26.

Users configure a service URL, API key and model name. The first release uses a Chat Completions-compatible interface. Keys stay in the OS credential store; SQLite does not store plaintext keys. AI receives only statistical aliases, classifications, counts and changes. Real identity mappings remain local.

Local rules aggregate important changes before requesting AI analysis. Automatic analysis defaults to 20 calls per day, is configurable, and is disabled at zero. Reserve allowance atomically before sending; retries count toward the budget, while manual preset follow-ups are counted separately. Local features continue without a service or remaining allowance.

Provide advice cards and preset follow-ups only. Model output is an untrusted explanation, with no filesystem or command-execution capability. Present causal inferences as possible causes. Action entries only open a local cleanup preview.
